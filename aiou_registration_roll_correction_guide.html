📌 What are Registration No. and Roll No. & Why Correction Matters?

  • **Registration Number (Lifelong Code):** Yeh aap ka permanent computer record code hai jo pehle admission par assign hota hai. Transcripts, LMS, aur provisional certificates isi number par issue hote hain.
  • **Roll Number (Semester Exam Code):** Yeh har semester exam paper check aur checking desks ke liye code hota hai jo roll slip par darj hota hai.

Agar is data me microscopic error bhi shamil ho jaye, to aapka pure semester ka exam result **R/L (Result Late)** status me chala jata hai ya database record trace na hone par zero marks lagte hain!

📌 When is Registration Merge/Correction Required? (Merge of Record)

  • ✅ **Duplicate Registrations (Intehaye Ahem):** Jab student ghalti se purani registration chupa kar naye program ke liye apply karta hai aur university do mukhtalif ID numbers (e.g. 21PGA05432 & 23PGA09412) issue kar deti hai.
  • ✅ **Typographical Mismatch:** Portal ya ID card par registration card alphanumeric codes misprint hon.
  • ✅ **Roll No. Mismatch in LMS:** Exam hall me roll number kuch aur ho aur LMS Portal profile profile data me roll code mismatch ho.
  • ✅ **Ombudsman Directives:** Legal validation checks verification desk se pass na hone par exam controller ka error query issue karna.
Ahem Mashwara (Best Time to Apply): Tamam records ki correction/merging **degree print hone se pehle** karwayin. Degree ban jane ke baad registration number correction karwana extreme level par mushkil aor long-term process ban jata hai!

📝 Step‑by‑Step Procedure to Correct or Merge Academic Registry

  1. Download & Print Form: Upar diye gaye official PDF download button par click kar ke standard print sheet save karein aur print nikalwayin.
  2. Provide Accurate Student Credentials:
    • Apna Mukammal Naam, CNIC, and current active Program details darj karein.
    • **Incorrect / Duplicate Registration Number:** Woh alphanumeric code jo ghalat hai ya jis registration record ko delete karwana hai.
    • **Correct / Primary Registration Number:** Aapka main authentic registration code jis ke sath doosre record ko merge/join karwana hai.
  3. Gather Legitimate Academic Proofs:
    • Attested copy of Student CNIC / ID Card.
    • Copy of matric/inter board certificate for verification match.
    • **Duplicate merge support:** Dono registration numbers par issue hone wali fee receipts, admission letters ya roll slips ki photo copies.
    • **Affidavit bayan-e-half:** Rs. 50/100 stamp paper par certified bayan ke aap duplicate registration merge karwa rahe hain taakay records clear ho sakein.
  4. Pay Correction / Merging Fee:
    • **Record Merge / Registration Change Surcharge:** Standard Rs. 500/- to Rs. 1,000/- challan code fee (Fee grid details niche shamil hain).
  5. Send to Examinations Directorate:
    • Complete application record, fee receipts aor affidavits ko envelope me seal kar ke raw courier karein: **Director of Examinations, Correction Cell Section, Block No. 3, Sector H-8, AIOU Main Campus, Islamabad – 44000**.
Pro Tip for Duplicate Mergers (Ahem Tarin Hack): Duplicate registration merges ke dauran, jab application approve ho jaye, to IT cell se **Unified Transcript Update** zaroor check karwayin takay donon IDs par clear kiye gaye sabhi courses aik hi final certificate par transfer ho sakein!

❓ Frequently Asked Questions – Merging & Registration Support

🔹 Agar mere 2 registration numbers hain aur main merge na karwayon to kya ho ga?
Agar aap merge nahi karwayin ge to do mukhtalif IDs par clear kiye gaye courses alag hi rahenge aur AIOU aap ki final degree process nahi kar sakay ga, kyunki single degree ke liye unified register record laazmi hai.
🔹 Kya roll number correction online ho sakti hai?
Nahi. Registration merges aur roll corrections direct physical databases me changes demand karti hain jis ke liye physical docs verify kiye jate hain, is liye raw registry courier karna laazmi hai.
🔹 Verification check karne ka easiest tareeqa kya hai?
Jab application approve ho jaye, to active CMS profile login karein. Wahan portal credentials me primary ID tab update ho chuki ho gi aor secondary duplicate account permanently disable show ho ga.
🔹 Kya ghalat roll number se diye gaye paper ka result zaya ho jata hai?
Zaya nahi hota balkay Result Late (R/L) category me block ho jata hai. Roll number application processing approve hote hi central database check paper codes update kar ke result profile me update kar deta hai.
