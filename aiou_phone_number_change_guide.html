📌 When is Phone Number Correction Required? (Tabdeeli e Number)

Aapko darj-zail situations me dynamic contact record badalna zaroori hota hai:

  • ✅ **Lost SIM Card:** Aapka purana mobile number block ho chuka ho ya sim gum ho gayi ho.
  • ✅ **Typing Error at Portal:** Admission time online data operator ne data entry ke dauran number digit misprint kar diya ho.
  • ✅ **No SMS Alerts:** University ke official academic SMS alerts receive na ho rahe hon (Exams schedule / Tutoring data updates).
  • ✅ **Network Conversion (MNP):** Network switch (porting) hone ki wajah se automatic short-code system standard SMS delivery block kar raha ho.
Ahem Mashwara (Best Time to Apply): Apna mobile number exams dates se kam az kam **30 din pehle** update karwayin, taakay physical roll number tracking slips aor center locations alerts sahi time par aap tak pohanch sakein!

📝 Step‑by‑Step Procedure for Phone Number Correction

  1. Download PDF: Upar diye gaye official PDF download button par click kar ke standard print sheet save karein.
  2. Provide Accurate Student Info:
    • Apna Mukammal Naam, CNIC, Enrollment ID (Student ID) aur target Program likhein.
    • **Purana Number (Old Mobile):** Jo ghalat number university database me show ho raha hai.
    • **Naya Number (New Mobile):** Apna active aur non-ported contact number likhein jo har waqt online rehta hai.
  3. Attach Legal Verification Proofs:
    • Attested CNIC / B-Form copy.
    • Copy of last paid semester fee Challan.
    • **SIM ownership proof:** Active franchise biometric slip, SIM registration certificate ya utility postpaid mobile bill (jo yeh sabit kare ke number aapke ya aapke parent ke CNIC par active hai).
  4. Pay Surcharge/Fee (If Applicable):
    • **Regular active student phase:** Rs. 0/- (Mukammal Free of Cost).
    • **Post degree transcript updates phase:** Token fee Rs. 200/- to Rs. 300/- (Verification charge).
  5. Admissions & IT Cell Submission:
    • Complete application package ko courier karein direct: **Director Examinations / Admissions Support Cell, Admin Block, Sector H-8, AIOU Main Campus, Islamabad – 44000**.
Pro Tip for MNP/Ported Numbers (Ahem Nuqta): Zong se Jazz, ya Telenor se Ufone par switch kiye gaye (Ported SIMs) short-code alerts aksar reject karti hain. AIOU SMS system direct alert delivery ke liye **Standard Non-Ported SIM Number** update karne ki advice deta hai taakay delivery block na ho!

❓ Frequently Asked Questions – Contact Support Desk

🔹 Kya main online portal se number tabdeel kar sakta hon?
Jee haan! Aap CMS portal par login kar ke "My Profile" tab me contact details edit kar sakte hain. Lekin physical roll number alert systems aor main exams record me permanent shifts ke liye physical application submit karna behtareen tareeqa hai.
🔹 Kya ported SIM (ek network se doosray par tabdeel ki gayi) par alerts aate hain?
Aksar networks short-code commercial SMS alerts block kar dete hain. Ported number par SMS na aane ki surat me apne SIM operator helpline par call kar ke short-code codes whitelist karwayin.
🔹 Number update hone ke baad validation check kaisey karein?
LMS login portal par ja kar "Forgot Password" par click karein. Agar database update ho chuka hai, to automatic verification OTP SMS aap ke naye mobile number par foran delivered ho ga.
🔹 Kya main backup communication ke liye doosra contact number shamil kar sakta hon?
Jee haan. Application form me active secondary number box me alternate number likhein taakay main number network issues ya band hone ki soorat me backup alerts delivered ho sakein.
